# 📱 QR Code Generator

> A modern, elegant QR Code generator with an animated glassmorphism interface, bilingual support and instant PNG downloads.

QR Code Generator is a lightweight web app that creates QR Codes for plain text, URLs or WiFi credentials in just a few clicks. The project combines a premium animated interface, fully customizable colors and size, and a smooth, professional experience, all built with vanilla HTML, CSS and JavaScript.

## ✨ Main Features

- 📝 Generate QR Codes for plain text, URLs or WiFi network credentials
- 📶 WiFi mode supports WPA/WPA2, WEP and open networks, ready to scan and connect
- 🎨 Fully customizable QR Code color, background color and size
- ⬇️ One-click PNG download of the generated QR Code
- 🌍 One-click language toggle between European Portuguese and English, remembered between visits
- 🎬 Smooth animations and micro-interactions — floating gradient orbs, animated tab indicator, glassmorphism cards and hover effects
- 📱 Fully responsive layout, from mobile to desktop

## ▶️ How to Run

Open the project directly in your browser, or serve it locally with:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/
```

## 🧩 Project Highlights

This project focuses on delivering a smooth and modern experience while keeping the implementation simple, lightweight and easy to understand. It is built with pure web technologies to remain accessible, portable and easy to extend. The selected language is stored in `localStorage`, so it persists between visits.
